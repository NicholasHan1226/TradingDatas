## Implementation and local acceptance

- Library: 200 identities, 60 bilingual guides (59 six-section guides, one
  four-section abstract orientation), 140 summary records. The eight core
  journeys, 24 core works, three supplementary question routes and six tutorials
  remain unchanged. Featured identifies guides from metadata, not loaded text;
  both locales and every topic retain the same source/bookmark identity.
- Materials: all 150 previously summary-only records were individually curated
  using existing summaries and stated inputs: 41 linked, 109 deliberately empty.
  After the ten guide overrides the whole library has 77 linked and 123 empty
  selections. Missing assignments safely produce no links. None of this is a
  full-text review of the remaining 140 works.
- Body loading: a build-time virtual module per guide; the public discovery
  projection omits body/guide-limit paragraphs. Loading/error/retry preserve
  source and bookmark actions. Successful bodies are cached with both languages;
  rejected requests leave the application cache so explicit retry can run.
  Cancellation ignores late responses; section anchors wait for body insertion.
  Browser behavior of network retry/focus still needs the acceptance below.
- Source/internal QA profiles remain outside the production discovery bundle.
  No style-system, account, API, dependency, lockfile, workflow, collector,
  registry, credential or production change.
